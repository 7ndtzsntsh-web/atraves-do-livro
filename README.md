# Através do Livro — Clube de Leitura com Dani Valentim

Landing page oficial de alta conversão para o **Clube Através do Livro**, idealizado e mediado por **Daniela Valentim**.

## 📖 Sobre o Projeto
- **Design System**: Editorial moderno, Mobile-First, paleta baseada em tons de pergaminho suave (`#FAF6F0`), índigo profundo (`#1E1B4B` / `#4F46E5`) e dourado caramelo (`#C29352`).
- **Zero Scripts Inline**: 100% de conformidade com a política CSP `script-src 'self'`. Toda a interatividade reside em `js/app.js`.
- **Integrabilidade**:
  - Links dinâmicos de WhatsApp com mensagens contextualizadas (`encodeURIComponent`).
  - Link oficial para o Instagram de Daniela Valentim ([@danielasvalentim](https://www.instagram.com/danielasvalentim/)).
  - Formatação padronizada contínua para números de telefone: `(11) 945549000`.
- **Segurança**:
  - Configuração de cabeçalhos de nível militar em `vercel.json` (CSP rigoroso, Referrer-Policy, nosniff, DENY de iframes).

## 🚀 Tecnologias
- HTML5 Semântico & Acessível
- Tailwind CSS (Pré-compilado em `css/style.css`)
- FontAwesome 6 (Assets locais)
- JavaScript Vanilla modular em `js/app.js`
